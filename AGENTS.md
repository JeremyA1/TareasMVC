# TareasMVC

## Continuidad visual

Al crear o modificar vistas o componentes visuales, seguir [ESTILO_VISUAL.md](ESTILO_VISUAL.md) y reutilizar las clases y variables de `TareasMVC/wwwroot/css/site.css`.

El comando conversacional **«Aplica el estilo TareasMVC»** significa aplicar esa guía a las vistas o componentes indicados por el usuario; si no indica un alcance, usar los cambios de interfaz de la tarea actual. Mantener el diseño sutil, Bootstrap y los bindings de Razor/Knockout existentes.
